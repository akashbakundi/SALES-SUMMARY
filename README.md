# SALES ANALYSIS DASHBOARD (EXCEL + POWER BI)

## PROJECT OVERVIEW:
This project is a **Sales Analysis Dashboard** created using **Excel** (for raw data preparation) and **Power BI** (for visualization and reporting).  
The goal was to transform real-world sales data into clear, actionable insights for business decision-making.

## KEY FEATURES:
- **Executive Summary**: Total sales of ₹10.53M, 1000 orders, and an impressive 91.25% profit margin.
- **Monthly Sales Trend**: Visual breakdown of performance across the year.
- **Category-wise Sales**: Comparison of Furniture, Electronics, and Office categories.
- **Product Analysis**: Top 10 products ranked by profitability and contribution.
- **Customer Insights**: Repeat vs new customers, top customers by sales, and state-wise distribution.
- **Profitability Metrics**: Detailed view of category and subcategory performance.

## TOOLS USED:
- **Excel**: Data cleaning and preparation  
- **Power BI**: Dashboard design, DAX calculations, and interactive visuals
